What this is

62GEMSDOE implements one lane of the DOE GEMS Prize (Drivendata #306, GeoDAWN region, northwestern Great Basin, Nevada): use the ~15 ka Lake Lahontan highstand shoreline as a near-level datum, find where that datum is stepped in elevation or deflected laterally along strike, and ship those structures as a legal, unique GeoTIFF.

It has four parts: an exact re-implementation of the organiser's metric (verified against the published worked example and a brute-force transcription); the lane detector itself (isobase fit, throw-window flags, strike-parallel trace extension); a preregistered spatially-blocked hide-and-recover holdout with equal-budget controls; and a fail-closed submission writer whose output is validated by re-reading the bytes from disk.

Honest limits of this page

  • No score here is organiser-verified. Every number is HOLDOUT-DTI (with evaluator version, withheld-positive count and 95% CI) or ORGANIZER-CONFIRMED (copied from a submission-page receipt for an earlier file).

  • There is no absolute DEM in the official stack (IR-62-DEM-01). The isobase is fit in detrended-elevation space; absolute Lahontan shoreline elevations are not used or claimed.
  • The submitted file is a candidate, not a proven improvement.
