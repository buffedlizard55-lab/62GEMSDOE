The question

Why did the 0.2778 file score highest, and can we beat it? The 0.2778 artifact is the family's 0.2708 emission (40,199 dots) with every dot within 200 m of the mapped catalogue deleted (2,545 dots removed, 37,654 left). For unit-valued, non-overlapping dots the published index reduces to

DTI = c·N / (α·N + β·|G|)          c = mean kernel credit per dot, N = emitted mass, |G| = truth mass

Deleting a dot that earns no credit lowers N while leaving the pooled credit T unchanged, so DTI rises mechanically. That is a precision edit, not a discovery. The same algebra inverts the two owner-recorded rows of the family to give c ≈ 0.122 and |G| ≈ 12,000 cells — and it reproduces the observed 0.2778 to within 0.02 %:

What the lane did

  1. Datum mapping. 90,664 wave-planed cells inside the published deformed-elevation window (1313.5–1345.8 m; literature range 1318.4–1340.8 m) → 176 benches.
  2. Level separation. The residual histogram is multi-modal (modes at -10.2, -7.2, -4.2, -1.2, 1.8, 4.8 m) — the stacked-shoreline mimic. The dominant strand (176 benches) is kept so a Sehoo bench is never contrasted with an Eetza bench.
  3. Isobases. Robust 3rd-order global fit (σ = 12.16 m) for the domal rebound + northward tilt, then a locally robust plane fit on the single strand: σ = 2.99 m, i.e. below the published 3 m elevation-method resolution.
  4. Flags. 6 steps (|Δresidual| ≥ 3 m between benches ≤ 5 km apart) and 9 lateral deflections (≥ 35° azimuth change). A sensitivity screen over the slope gate (2.5/3.0/4.0°) and minimum patch size (4/8 cells) returns 3–6 steps in every configuration — a handful, as the brief anticipated.
  5. Traces. Fault azimuth from the datum geometry, not the local DEM grain: a vertical step means the fault crosses the shoreline (az + 90°), a lateral deflection means it runs along it (the Pyramid Lake fault-zone case). 12 traces survive evidence-gated extension (coherence ≥ 0.15, relief ≥ 4 m), mean length 6800 m.
  6. Emission. Unit dots at 300 m kernel-matched spacing, ≥ 200 m from the mapped catalogue. 225 dots.

Why the holdout number is unusually trustworthy here, and also does not answer the real question. The lane reads the catalogue for nothing except an exclusion gate that can only remove mass, so withheld positives provably cannot help it — this is a leak-free hide-and-recover, unlike every catalogue-reading method in the family. But the competition's target is exactly the fault population the catalogue lacks and the organizers mask out of scoring, so the number is a lower bound on recovering a mapped population and says nothing about the hidden target. Both facts are stated wherever the number appears.
