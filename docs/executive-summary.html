2. The seven things the portal checks, and where each one is satisfied

The competition accepts a single-band GeoTIFF (.tif), or a .zip containing a single GeoTIFF, matching the submission format's CRS, shape and geotransform (submission form text, quoted by the owner), and the format spec asks for a single layer, 32-bit float, values between 0 and 1, same CRS / resolution / bounds as the training data (problem description, page 967).

7no NaN inside the footprintnan_count = 0, all_finite = trueall-finite zeros are written outside the footprint and no nodata tag is set (nodata = null)

Checks 6 and 7 are the two that produce the portal error “Predicted values must be in range [0, 1]”. Both failure mechanisms are structurally absent here rather than merely avoided:

  • a float32 nodata sentinel such as -3.4028235e38 survives as a wild value inside the valid

footprint → this file has no nodata tag at all;

  • a NaN nodata tag makes the reader return NaN, which is not in [0, 1] → this file writes

all-finite zeros outside the footprint.

The receipt is not built from the in-memory array; grid.check_submission re-opens the file from disk and counts. See evidence/h62g/receipt.json.

4. What to submit instead, if a slot is going to be spent

The standing brief says promotion to a real slot is a separate selector step. This session's measurement points the selector at one file:

buffedlizard55-lab/GEMSDOE32 → docs/downloads/gems32-bayesopt-dilation-scarp-d28-20261004-zeros.tif (302,357 bytes, 45,000 dots).

Measured on the same independent off-catalogue instrument as everything else in this repository, its mean 300 m kernel credit is 0.29294 per dot — 3.0× the submitted champion family (0.09892 at the same mass), 3.4× this session's quarantined H62-I, and 6.8× this session's in-lane H62-G. It appears in no score registry anywhere in the group's 73 public repositories, i.e. it has never been submitted.

Read the caveat before acting on it. 0.29294 is a proxy-instrument credit, not an organizer score, and that instrument is a 1:750 k geological compilation which favours scarp-like geomorphology over genuinely new faults. The closed form turns 0.29294 at 45,000 dots into 0.71 at a planning truth mass of 12,000 cells — implausibly high, so discount it hard. Even discounted 4× it clears the top-5 cut-off of 0.3333. This session did not copy that file into a submission: the standing brief forbids copying a previous submission.
