IR-63-01 — labels.tif is byte-identical to existing_faults.tif RESOLVED — not a defect

Both files hash to 7ba308cc…d4093 and have the same 60,988 positive cells. Earlier sessions logged this as a data-placement error. It is not: the competition's training labels are the known-fault catalogue — that is what you train on, and the scoring set is a different, expert-updated collection. The consequence is recorded because it matters: no file in this repository has ever been scored against the real hidden set, and the catalogue cannot serve as a held-out truth for the thing the competition measures.

IR-63-03 — the flagship repository's 0.2298 “labels DTI” is an in-domain number

That figure is quoted in buffedlizard55-lab/GEMSDOE as evidence the supervised branch works. Its own evidence file records the caveat: “Per-block catalogue DTI is in-domain (the shipped model trained on every label)”. This session measured the same setup out-of-domain and got AUC 0.50. The 0.2298 should not be used to argue for the supervised route.
