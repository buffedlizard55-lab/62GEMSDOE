How to read a projected DTI

DTI = T / ( α·S + β·K )        T = c_hidden · S
  →  DTI = c_hidden / ( α + β·K/S )
  →  c_hidden = r · c_proxy        (r calibrated on score-anchored registry rasters)

With S = 90,000, c_proxy = 0.18848, r ∈ [0.478, 0.775] and K ∈ [8,000, 12,000]:

K = 8,000K = 9,400K = 12,000
r = 0.478 (pessimistic) 0.332 0.318 0.294
r = 0.775 (optimistic) 0.539 0.515 0.476

Every cell of that table is a MODEL. It is conditioned on a proxy truth set (a 1:750 k geologic compilation), on a transfer constant fitted to nine owner-reported scores, and on a planning value for the hidden truth mass. It is not a score, and the organizer's number can land outside the band. The one number on this page that is MEASURED is the credit per unit mass.

What would move the band

  • A second, independent proxy truth set. The SGMC compilation favours bedrock faults in rough terrain, which is the single largest known bias in c_proxy.
  • An organizer receipt for any file in this repository. Three uploads (λ = 1.0, 0.5, and a null-mass probe) identify T, K and F exactly from the leaderboard returns, because DTI(λp) = λT / (λα(T+F) + βK). That converts the whole projection into a measurement. It is a selector decision, not a lane decision.
