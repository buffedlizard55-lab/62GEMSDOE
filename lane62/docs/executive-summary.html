4. Format-valid does not mean cleared for submission

Two independent mechanisms produce the portal error "Predicted values must be in range [0, 1]", and both are properties of the competition's own inputs: (M1) training_features.tif declares nodata = -3.4028234663852886e+38, the float32 sentinel, so any pipeline that passes a feature band through unchanged ships cells far outside [0, 1]; (M2) a submission carrying a nodata tag of NaN can be read by a whole-raster range check as containing values outside [0, 1]. This file is written all-finite with nodata = None, so neither can occur. The group's own ledger records the same score (0.1294) for a NaN-outside file and its all-finite twin, so nothing is lost. A NaN-outside twin with bit-identical in-footprint values is reproducible with python3 scripts/make_variants.py.
