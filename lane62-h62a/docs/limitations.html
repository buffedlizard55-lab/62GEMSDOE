Limitations, and what would unblock each

Stated up front rather than at the end. A limitation that is not written down is a limitation that will be rediscovered badly.

#limitationeffect on this laneunblock free & official?
1No absolute-elevation band (IR-62-DEM-01). Only detrended elevation (band 12) and its slope (band 19). An isobase is an absolute datum; detrending removes part of it. The fit is done in detrended-elevation space, so the absolute shoreline elevation cannot be used. 1m_DEM_links.csv from the DrivenData data tab → USGS 3DEP 1 m lidar. Yes — USGS 3DEP is public domain. Not obtainable from this sandbox (egress allowlist).
2100 m pixels. A 15–45 m shoreline step is 0.15–0.45 px of relief. The physical throw window had to be widened to 15–130 m to be detectable at all. same 1 m lidar sourceYes, as above
3Holdout truth is the visible catalogue (IR-62-HOLDOUT-01). The lane's premise is that it finds faults the catalogue misses, so the instrument cannot directly reward success. A holdout win is necessary, not sufficient; a holdout loss does not disprove the lane.the organiser's hidden label setNo — nobody has it
4No organiser score exists for any artifact here. Every number is HOLDOUT-DTI or ORGANIZER-CONFIRMED-from-an-earlier-file. The promote/negative verdict is computed from the holdout and the gates, not from a score. a weekly submission slot — a separate selector stepn/a
5Lateral deflections carry no signal at 100 m (IR-62-DEFL-01). Half the lane's flagging criterion is a measured null. Kept because the lane specifies it; reported rather than dropped.1 m lidarYes, as above
6Radiometrics are absent from the stack. Blocks hypothesis H62-C (K/Th clay-cap breach), the one signature diagnostic of geothermal rather than merely structural. USGS GeoDAWN release, ScienceBase item 657e1d85d34e23d3533209f7 Yes — public domain. Obtainability from this sandbox unverified.
7No GPU / no model training. This lane is deterministic signal processing, so nothing is lost — but the reference solution's U-Net route cannot be reproduced or blended here. a GPU runner plus pip install torch segmentation-models-pytorch Yes (software), no (hardware in sandbox)

What a next session should do first

  1. Obtain the 1 m lidar. It closes limitations 1, 2 and 5 at once and is the single highest-leverage unblock in this repository. Free, public domain, USGS 3DEP.
  2. Implement H62-B (isobase-parallel strike continuity: gaps between collinear mapped traces). No new data, ~3 h, and it targets catalogue incompleteness more directly than anything here.
  3. Obtain the GeoDAWN radiometric grid and implement H62-C. Highest ceiling of the five.
  4. Re-run the holdout at a finer buffer (2 px and 5 px) to check that the A3 result is not an artefact of the 3 px buffer choice.
  5. Do not spend a slot on any file whose holdout DTI does not beat the current holdout best, per the brief.
